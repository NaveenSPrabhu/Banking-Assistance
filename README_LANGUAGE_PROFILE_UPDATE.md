# Language + Profile Update

This update keeps the existing banking UI/colors and adds:

- Central i18next UI translation.
- English, Kannada, Hindi, Tamil, Telugu, Malayalam and Marathi resources.
- Login loads the user's `preferredLanguage` from the backend.
- Profile shows the real logged-in user instead of placeholder data.
- Profile -> Edit Profile updates user details and preferred language.
- Dashboard profile menu -> Change Language opens a working language selector.
- Language changes are applied immediately across React UI.
- Existing AI/voice/QR/workflow logic was not replaced.
- Responsive spacing/layout improvements were limited to preserving the same design on laptop and mobile.

## Frontend setup

From `Frontend`:

```cmd
npm install
npm run dev
```

The frontend package now includes `i18next` and `react-i18next`. The frontend lock file is intentionally regenerated by `npm install` so it matches the updated dependencies.

## Backend

The backend now exposes:

- `GET /api/auth/profile` (existing)
- `PUT /api/auth/profile` (new)

The update endpoint requires the existing Bearer JWT.

## Environment

The uploaded backend `.env` was not included in the deliverable for security. Restore/create your local `Backend/.env` with your existing database and JWT configuration before starting the backend.
